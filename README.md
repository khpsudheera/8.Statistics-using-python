# 📊 Statistical Analysis of Computer Sales Data
## 📌 Project Overview

This project focuses on applying core statistical concepts to analyze a computer sales dataset and derive meaningful business insights.
The objective is to understand purchase behavior, probability trends, and sales patterns using descriptive and inferential statistics.
The analysis is divided into two structured parts, covering probability analysis, data exploration, and statistical reasoning to support decision-making.

# 🎯 Business Objectives
- Analyze purchase likelihood based on computer specifications
- Estimate probabilities of selling premium computers
- Identify key factors influencing customer buying behavior
- Support data-driven decisions using statistical methods

# 📊 Dataset Description
Dataset contains detailed information about computer products
Key attributes include:
- RAM
- Storage
- Price
- Premium status
- CD drive availability
- Other technical specifications
- The dataset is used to simulate real-world retail and product analytics scenarios.

# 🛠️ Tools & Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

# 🔍 Key Analysis Performed
✔ Data Exploration
- Checked missing values and data types
- Performed basic data validation

✔ Probability Analysis
- Calculated probability of selling premium computers
- Analyzed conditional probabilities (e.g., premium computers with CD drives)
- Evaluated likelihood of purchases based on minimum specifications

✔ Statistical Reasoning
- Used descriptive statistics to summarize trends
- Applied probability concepts for business insights
- Interpreted results in a decision-making context

📈 Key Insights
- Premium computers show distinct purchasing patterns
- Higher specifications increase purchase likelihood
- Probability-based analysis helps predict sales outcomes
- Statistical methods can directly support pricing and product strategy

🧠 Learning Outcomes
- Practical application of statistics in business analytics
- Improved understanding of probability and data interpretation
- Hands-on experience with realistic sales data

Strengthened analytical thinking for business decision support
